## To-Do List App
A simple full-stack to-do list I build to practice putting a real frontend, backend, and 
database together. 

# What it does
Nothing fancy, it's just a to-do-list 
  - Add task
  - Check it off when it's done 
  - Delete a task you don't need anymore
  - Refresh the page and everything's still there, since it's
  saved to a database

  Stack
  - Frontend: React + Tailwind CSS
  - Backend: Node.js + Express
  - Database: SQLite
